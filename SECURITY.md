# Security

Please don't open a public issue for a security problem: a definition
that could harm a server, a signing problem, or a compromised image. Use
GitHub's private vulnerability reporting (the Security tab, "Report a
vulnerability").

Problems in CirrusUX itself go to
[CirrusUX's security page](https://github.com/asafelobotomy/CirrusUX/security).

If the signing key were ever exposed, CirrusUX would ship a new public key
in a release, and this catalogue would be re-signed with the new one.
